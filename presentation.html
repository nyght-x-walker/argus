ARGUS · THE FRAMING

Why this exists

IF WE ARE READING PLATES, WHY NOT DO SOMETHING WITH THEM

Argus reads license plates from images and video, checks them against a watchlist, and puts the verdict in front of an operator, who makes the call. It runs on one machine with no network: plate strings and file paths go in the log, images stay on disk.

0network calls shipped
1human per decision
11self-checks per launch
WHY BEHIND THE HOW
Offline-firstBooths don't always have internet. No network code means footage can't leak.
OF + docked panelsIt's the course stack. One window beats five tabs when watching a gate.
Heuristics, not DNNNo training data, no GPU. Contours we can explain beat a model we can't train.
EU-firstThe samples are EU plates. US/UK only rename the region; no verdict changes.
Human decidesA flag is a suggestion. A person signs Allow, Block or Review.
JSON storeAnyone can read it. No server to install next to a booth.
300 s cooldownOne banner per incident. Video would strobe without it.
Self-checksEleven per launch, replayed headless. That is the test suite.
DeterminismFixed thresholds, sorted ties. Same image, same answer on rerun.
SCOPE · ETHICS · CONTRIBUTIONS
Non-goalsReal-time tracking, trained models, per-state formats, enforcement use. Operator-assistance prototype on demo data.
MitigationsHuman decides; Authorized stays silent; unknown types fail closed; every hit is JSONL-auditable; no network code ships.
ContributionsOne pure pipeline for stills + video; region + fuzzy fixes with zero verdict change; a watchlist an operator can run.
