ARGUS · SCOPE AND CHOICES

Why this shape

Argus reads license plates from images or video, checks them against a watchlist, and shows the result to an operator. It runs offline, on one machine, with no network code. Plate text and file paths go to a JSON log; the images stay on disk.

The system never acts on its own. It flags; a person decides.

1human per decision

WHY THESE CHOICES
Offline-firstBooths don't always have internet. No network code means footage can't leak.
OF + docked panelsIt's the course stack. One window beats five tabs when watching a gate.
Contours, not DNNNo training data, no GPU, and we can explain every decision the detector makes.
EU-firstThe samples are EU plates. US/UK only rename the region; no verdict changes.
Operator decidesA flag is a suggestion. A person signs Allow, Block or Review.
JSON storeAnyone can read it. No server to install next to a booth.
300s cooldownOne banner per incident. Video would strobe without it.
Self-checksEleven per launch, replayed headless. That's the test suite.
DeterminismFixed thresholds, sorted ties. Same image, same answer on rerun.
SCOPE
What this isAn operator-assistance prototype on demo data. Stills and video, one pipeline, one watchlist, one operator UI.
What it isn'tNot a real-time tracker. Not trained models. Not per-state formats. Not for enforcement or evidentiary use.
HandlingEvery consequential call is made by a person. Authorized plates are silent by policy. Unknown types fail closed. Every hit is JSONL-auditable. Plate data can't leave the machine.
WHAT WE CONTRIBUTED
One pipelineDetect, read, repair, validate, match — shared identically by stills and video.
Region + fuzzy fixesReporting changed. No verdict changed.
An operator's watchlistEdit, delete, audit, decide. No hand-editing JSON.
